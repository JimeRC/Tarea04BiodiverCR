# Tarea04BiodiverCR

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un minilibro educativo interactivo sobre la biodiversidad de Costa Rica, utilizando el lenguaje de programación Java.

La aplicación permitirá explorar diferentes contenidos educativos mediante páginas informativas y realizar una actividad interactiva para evaluar los conocimientos adquiridos.

## Objetivo

Desarrollar una aplicación de escritorio aplicando programación orientada a objetos, arreglos unidimensionales y bidimensionales, ArrayList, manejo de excepciones y arquitectura MVC.

## Tecnologías utilizadas

- Java
- Apache NetBeans
- Maven
- Java Swing
- GitHub

## Contenido del libro

1. ¿Qué es la biodiversidad?
2. Animales de Costa Rica.
3. Ecosistemas y conservación.
4. Actividad interactiva.
5. Resultados e historial de intentos.
